# Student Management System

A console-based Java application for managing student records. It supports adding, listing, searching, updating, and removing students.

## Requirements

- JDK 22
- Apache Ant (or NetBeans with Ant support)

## Run in NetBeans

Open the project in NetBeans and run `StudentManagementSystem`.

## Run from the command line

```sh
javac -d build/classes src/studentmanagementsystems/*.java
java -cp build/classes studentmanagementsystems.StudentManagementSystem
```
